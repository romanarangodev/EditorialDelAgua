# Sitio web corporativo
La idea principal radica en mostrar un imagen digital adecuada al perfil de la empresa
<h3 align="left">Objetivo</h3>
El objetivo a alcanzar para este proyecto era que además de mostrar una imagen corporativa adecuada y profesional para esta editorial , uno de los requisitos más importantes era desarrollar un catálogo de publicaciones. Estas publicaciones están en formato de archivo PDF, por lo que requerian que el archivo se pudiera visualizar pero no descargar.

<h3 align="left">Herramientas y tecnologías</h3>
<ul>
  <li>Wordpress</li>
  <li>Kadence</li>
  <li>Programación incluida en un tema child</li>
  
  
</ul>
